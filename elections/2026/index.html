Methodology and sources

Results

All results come from the Electoral Commission of South Africa (IEC). This hub reads the official "Downloadable detailed results" files the IEC publishes for each province on its public reports portal. It checks for new or updated files every 5 minutes, downloads only a file that changed, and adds up its voting-district figures by municipality, province and nation (national totals only once all nine provinces are in). If the IEC grants API access, the hub switches to the official IEC API (api.elections.org.za), used within its request limits. Visitors never send requests to the IEC. If a source is unavailable, the last verified figures stay on show with the time they were captured.

Figures added up from the files are marked as from the IEC published files. Turnout is derived by this hub as the larger of ward or PR votes cast divided by registered voters, as the IEC defines it. Seat calculations and voting-district completion are not in these files, so they are shown only when the IEC API is connected.

Checks before anything is shown

No negative counts; no more voting districts reported than exist; party votes not above valid votes; percentages between 0 and 100; seats adding up to the council total; no duplicate parties. Records that fail are held back and logged. Missing figures are shown as unavailable, never as zero. Two times are kept: the IEC's report time and this hub's retrieval time.

Definitions

  • Voting districts reported is geographic completion (districts whose results the IEC has captured), not the share of votes counted.
  • Leading means most votes reported so far. Controls means more than half the council's seats in the IEC seat calculation. Exactly half is not a majority.
  • Ward, proportional representation (PR) and district (DC 40%) ballots are kept separate; party totals combine them as the IEC publishes them.
  • Coalitions or governing arrangements are never inferred from seats. They are listed only when confirmed by dated, authoritative reporting.
  • Party comparisons across years show "No comparable result" where a party did not contest.

Maps and boundaries

Municipal and ward boundaries are the Municipal Demarcation Board's 2026 boundaries (Spatial Hub). Past results are joined to today's map only where the municipality code still exists, with a warning that boundaries may have changed; areas without a match show "No comparable result".

Change events and insights

Events are generated only from changes between official snapshots: completed results, reporting milestones (25, 50, 75 and 90% of voting districts), seat calculations, council outcomes, lead changes in reported votes (marked provisional) and official corrections. No AI writes figures or stories.
